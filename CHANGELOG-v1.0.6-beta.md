# CHANGELOG v1.0.6-beta — точечные правки после 1.0.5

*1 сентября 2026*

## Новое

- Индикатор «печатает…» в MC Messenger (клиент + API)
- Догрузка истории чата при скролле вверх
- Шаринг сборки и мира/LAN из вложений чата
- Статусы прочтения ✓ / ✓✓ в личных чатах
- Бейдж обновления в titlebar
- Эмоции в skinviewengine (wave, dab, dance и др.)

## Улучшения

- Минимальный размер окна 1100×800
- Модалки центрируются относительно области ниже titlebar
- Выше модалки профиля / инфо о чате
- Упаковка Windows: asar без exe/zip/музыки/screenshots, `afterPack` кладёт updater/unins рядом с exe, locales только en-US+ru (~490 МБ win-unpacked)
- DnD файлов в управление сборкой; иконки ярлыков Windows через `.ico`
- Кастомный caret и аккуратный скролл ленты чата

## Исправления

- Главная снова как в коммите (без Steam-эксперимента)
- Убран неиспользуемый `lucide` из зависимостей
- Старт после обновления: в asar снова включён `protodef/src` (падение `Cannot find module './src/index.js'`)
