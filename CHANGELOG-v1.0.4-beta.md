## 📦 v1.0.4-beta — UAgent, предпросмотр миров, зависимости модов и шаринг сборок

*17 августа 2026*

Самый большой beta-релиз после 1.0.2: встроенный ИИ-агент, 3D-предпросмотр миров, «умные» зависимости модов как в Prism, импорт и шаринг сборок, зеркало релизов с сайта и переработанная главная. (1.0.3 была точечным патчем каталога — весь продуктовый объём здесь.)

### 🚀 Новое в этом релизе

**UAgent — ИИ-агент в лаунчере**

- В боковой панели вкладка «Агент» с чатом: стриминг ответа, стоп, повтор, копирование
- Сценарии одним кликом: разбор краша, оптимизация, новая сборка, поиск мода
- Вложения к сообщению: сборка, мод / ресурспак / шейдер / датапак, файл, crash / latest.log, веб-поиск, диагностика
- Агент умеет управлять сборками: создавать и править, ставить моды, крутить Java / RAM / JVM, читать логи и конфиги, запускать игру (опасные действия — с подтверждением)
- После краша — кнопка «Решить проблему с агентом»
- Закрытый доступ по ключу тестировщика: раздел UAgent в настройках и онбординг при первом запуске

**Предпросмотр миров в сборке**

- Вкладка «Миры»: открыть мир в 3D без запуска Minecraft (WASD + мышь)
- Live-предпросмотр для поддерживаемых версий; для более новых — упрощённый live или полный экспорт
- Маркер точки сохранения со скином и ником игрока; текстуры блоков из клиентского jar
- Понятные бейджи режима: Live / Live≈ / Экспорт / не поддерживается

**Зависимости модов (как в Prism)**

- При установке с Modrinth автоматически подтягиваются обязательные зависимости (транзитивно), версии подбираются под Minecraft и загрузчик сборки
- Уже установленное пропускается; конфликты — с подтверждением; опциональные зависимости только предлагаются в логе
- В статусе видно, сколько зависимостей доустановилось
- Тот же резолв работает у агента при `install_mod`

**Импорт и шаринг сборок**

- Импорт `.mrpack` / `.zip`: Modrinth, CurseForge и архив инстанса (версия, loader, overrides, контент)
- «Поделиться сборкой» — ссылка для друзей (моды / паки / настройки; миры не передаются)
- Импорт по ссылке / deep link с предупреждением о безопасности

**Главная и новости**

- Дашборд: герой выбранной сборки, «Продолжить игру», инсайты по библиотеке и наигранному времени
- Новости с сайта лаунчера прямо в клиенте

**Кабардинский язык**

- Добавлена локаль `kbd` (Къэбэрдейбзэ) — теперь 6 языков интерфейса

**Установщик: зеркало релизов с сайта**

- Установщик и updater сначала берут zip с сайта лаунчера; если зеркало недоступно — fallback на GitHub

### ⚡ Улучшения

**Загрузки и прогресс**

- Процент, объём и скорость при скачивании модов, модпаков и Java; для пакетной загрузки — счётчик `i/n`
- Живой прогресс по ходу файла модпака (полоска больше не «молчит» до конца каждого jar)
- В установщике: объём, сглаженная скорость и оценка оставшегося времени

**Сборки и интерфейс**

- Единая иконка по умолчанию для новых сборок (`newBuild`) — и в «Моих сборках», и в чипе агента
- Иконки вкладок настроек (включая UAgent) и действий (импорт, папка, лог, обновление)
- Селект языка показывает нативные названия (Русский, English, …) и не ломает кириллицу

**Локализация**

- Новые строки на всех языках: агент, миры, импорт, шаринг, главная, зависимости модов

### 🔧 Исправления

- **Селект языка** — подписи и выбранное значение больше не сбиваются после смены локали
- **Зависимости модов** — меньше установок «голого» мода без Fabric API и аналогов; конфликты не игнорируются молча
- **Скорость резолва зависимостей** — версии фильтруются на стороне Modrinth, проекты/версии запрашиваются пачками, зависимости качаются параллельно
- **Установка / обновление** — при проблемах с GitHub клиент ставится и обновляется с зеркала сайта
- **Предпросмотр миров** — корректные отказы для старых миров и явный путь через экспорт для слишком новых
- **Импорт архивов** — устойчивее к кириллице и длинным путям при разборе zip
