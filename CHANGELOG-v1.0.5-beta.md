## 📦 v1.0.5-beta — MC Messenger, шаринг миров с друзьями, CurseForge-зависимости и экспорт сборок

*29 августа 2026*

Релиз про общение и совместную игру: встроенный **MC Messenger**, приглашения в LAN-мир через туннель, экспорт сборок в ZIP / `.mrpack`, зависимости модов **с CurseForge** наравне с Modrinth, честный импорт zip и спокойный установщик без ложных ошибок.

### 🚀 Новое в этом релизе

**MC Messenger — чаты в лаунчере**

- В боковой панели вкладка «Чаты»: личные диалоги, группы, друзья, поиск по нику
- Сообщения, вложения, статусы прочтения; звуки отправки и входящего
- Профили, аватар / обложка, роли в группе, блокировки и заявки в друзья
- Активность: что играет собеседник, хостит ли мир
- Сессия через Microsoft или Ely.by (тот же аккаунт, что в лаунчере)

**Шаринг мира с друзьями**

- В Minecraft: «Открыть для сети» → в Messenger: «Поделиться с друзьями»
- Лаунчер находит LAN-порт по логу игры и поднимает исходящий туннель к relay
- Друзьям уходит приглашение с адресом; можно скопировать IP, зайти или скачать сборку
- Вкладка «Миры» — список открытых миров друзей
- После перезапуска лаунчера активный шаринг пытается восстановиться

**Экспорт сборки**

- Экспорт в **ZIP** (удобно для Prism и других лаунчеров) и в **`.mrpack`** (Modrinth App)
- В архив: моды, ресурспаки, шейдеры, датапаки, конфиги и типичные overrides — без библиотек игры и миров
- Прогресс упаковки в UI; отмена и понятные ошибки

**Зависимости модов с CurseForge**

- При установке с CurseForge обязательные зависимости подтягиваются так же, как у Modrinth (транзитивно, под Minecraft + loader)
- Резолв идёт через каталог сайта лаунчера (`project` / `versions` / файл CF)
- Fingerprint CurseForge для сопоставления локальных jar с проектами каталога
- Плейсхолдеры обложек для модов без иконки (Modrinth / CurseForge)

**Офлайн-аккаунт: границы онлайн-фич**

- Вкладки **Чаты** и **Скины** скрыты / недоступны на офлайн-аккаунте
- Понятные модалки: нужен Microsoft или Ely.by
- Скины на офлайне не синхронизируются с сетью — только локальный предпросмотр в лаунчере

### ⚡ Улучшения

**Консоль разработчика**

- Оформление в токенах клиента (фон, акцент, шрифт Nekst)
- Уровни логов: info / warn / error / **run** / done / exit; запуск Minecraft — синий Run, а не ложный Done
- Копирование с анимированным тостом; иконка копирования; синхронизация темы и акцента с основным окном

**Импорт сборок (zip / модпаки)**

- Если часть файлов не распаковалась или не скачалась — больше не «тихий успех»
- Toast и статус: импорт с пропусками + подсказка проверить консоль и содержимое сборки
- Устойчивее к именам в UTF-8 и частично битым архивам

**Движок скинов (skinviewengine)**

- Доработаны студийная атмосфера, post-FX и product-visuals: спокойнее свет и композиция предпросмотра
- Стабильнее цикл сцены при смене скина / плаща

**Интерфейс и ассеты**

- Новые иконки: чаты, карточки, список, Microsoft, Ely.by, копирование, зарегистрированный пользователь
- Звуки Messenger: `send` / `message`
- Обновлён splash title; убраны тяжёлые треки из `MusicForUClient` (меньше вес репозитория и дистрибутива)

**Шаринг и deep link**

- Доработки шаринга сборок по ссылке и импорта по deep link в связке с Messenger / экспортом

### 🔧 Исправления

**Установщик / updater / unins000**

- После успешной установки, обновления или удаления больше не показывается «Не удалось выполнить операцию»
- Занятый `uclient.exe`, сбой ярлыка (COM) или хвост реестра не затирают карточку успеха
- Перед переустановкой / обновлением / удалением клиент корректно завершается (`taskkill`)
- Распаковка: один заблокированный файл не роняет всю операцию
- Если побочный эффект уже прошёл — UI восстанавливает success вместо ложной ошибки

**CurseForge и каталог**

- Убран ранний «однофайловый» путь установки CF, из‑за которого зависимости не резолвились
- Зависимости CF приходят в том же формате, что и Modrinth (типы связей нормализуются на стороне каталога)

**Офлайн и безопасность фич**

- Нельзя обойти блокировку чатов / скинов переключением вкладки на офлайн-аккаунте

**Импорт**

- Неполные zip больше не маскируются под полную установку сборки

### 📦 Состав дистрибутива (для сборщиков)

- В релизный `latest-windows-amd64.zip` нужно класть свежие **`updater.exe`** и **`unins000.exe`** (собраны из `installer/` через `build_installers.cmd`)
- Версия клиента: **1.0.5-beta** (`package.json`)
